# ABYSS://CACHE

Подводная игра-расследование на голом canvas. Ни сборки, ни зависимостей —
открой `index.html` в браузере.

Ты — PING-7, диагностический дрон в замкнутом океане размером 14000×30000,
разложенном на 50 замкнутых в кольцо слоёв глубины. Каждые восемь минут
система откатывается к резервной точке и начинает заново. Один файл не
восстанавливается уже неизвестно сколько циклов.

Задач тебе не выдадут. Смотри, что не сходится.

## Как играть

| | |
|---|---|
| мышь | тяга. дрон тяжёлый, тормозить надо заранее |
| ЛКМ | фонарь. держать луч на объекте, пока не вскроется. единственный способ добыть энергию — и самый громкий |
| ПРОБЕЛ | коротко — импульс сонара: метит всё ключевое вокруг именем и дистанцией. держать — замереть, стабилизация, медленная зарядка |
| колесо | слой глубины |
| T | терминал (TAB дописывает, ↑↓ листают историю) |
| M | журнал: слева что понято, справа что нет |

Всё сюжетное — розовое и пульсирует. Больше в этом мире розового нет ничего,
поэтому цвет читается без подписи. Чем ближе ключевой объект, тем чаще зов.

Открытые вопросы в журнале — единственная навигация. Подсказок в HUD нет:
всё, что игра говорит, она говорит голосом самого дрона.

## Проверка

```
node test/headless.js
```

Прогоняет встроенный self-check вне браузера (минимальный DOM/canvas), затем
шагает симуляцией: экономику энергии, все фазы цикла, каждый гейт кадра и оба
финала освобождения. То же самое в браузере — открыть `index.html#test` и
смотреть консоль.

## Устройство

| файл | что внутри |
|---|---|
| `js/config.js` | константы мира и чистые правила: зоны, гейты кадров, улики, мысли |
| `js/state.js` | сохранение, знание игрока, ввод, терминал, события-паузы |
| `js/world.js` | симуляция: свет, энергия, преследователи, звезда, финалы |
| `js/render.js` | отрисовка и журнал |
| `js/fx.js` | частицы |
| `js/audio.js` | синтез звука через WebAudio |
| `js/main.js` | загрузочный экран, главный цикл, эпилоги |

Дизайн-документ слоя расследования — в
[`docs/superpowers/specs/`](docs/superpowers/specs/).
